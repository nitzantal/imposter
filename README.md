# המתּחזה — משחק מילים בעברית

משחק דפדפן סטטי, ללא שרת, ללא מסד נתונים וללא צורך בחשבון משתמש.

## קבצים

- `index.html` — מבנה המשחק
- `style.css` — עיצוב רספונסיבי לטלפון
- `game.js` — לוגיקת המשחק
- `words-he.js` — אוצר המילים בעברית

## כללי המשחק

1. בוחרים 3–20 משתתפים.
2. מגדירים זמן חשיפה, ברירת המחדל היא 5 שניות.
3. האתר בוחר מילה עברית אקראית ומשתתף אחד אקראי כמתחזה.
4. כל משתתף פותח קופסה אחת בלבד.
5. הקופסה מציגה את המילה או "המתחזה" למשך הזמן שהוגדר.
6. לאחר סיום החשיפה הקופסה מסומנת כפתוחה ולא ניתן לבחור אותה שוב.

הכול מתבצע מקומית בדפדפן.
