# אליאס — משחק מילים בעברית

משחק דפדפן סטטי (ללא שרת וללא חשבון), באותו סגנון של "המתחזה". מכשיר אחד עובר בין הקבוצות.
פותחים את `index.html` או מפרסמים את התיקייה כמו שהיא.

## מה אפשר להגדיר (הכול נשמר אוטומטית במכשיר)

- 2–8 קבוצות: שם, צבע ואימוג'י לכל קבוצה
- זמן לתור, יעד נקודות או מספר סיבובים, קנס על דילוג, סיבוב הוגן, התייחסות למילה האחרונה
- רמה (ילדים / נוער / מבוגרים, אפשר כמה יחד) וקטגוריות
- צלילים, רטט, מסך דלוק, אזהרת זמן

## מאגר המילים

- ברירת המחדל נמצאת ב-`words-alias-he.js` (רמה ← קטגוריה ← מילים מופרדות בפסיקים).
- בתוך המשחק: **עריכת מאגר המילים** — הוספה (כולל קטגוריות חדשות), מחיקה, ייצוא וייבוא של קובץ JSON, ושחזור המאגר המקורי.
- השינויים נשמרים ב-`localStorage` של הדפדפן ולא נכתבים לקובץ. כדי להעביר אותם למכשיר אחר או לקבוע אותם לצמיתות — ייצוא ואז הוספה לקובץ המילים.
- מילים שכבר הופיעו לא חוזרות עד שכל המילים הזמינות נוצלו.

## מבנה

| קובץ | תפקיד |
|---|---|
| `engine.js` | תורות, ניקוד, תנאי סיום (משותף לכל מצב) |
| `modes.js` | הגדרת מצבי משחק (כפתורים, מילים אסורות, מאגר) |
| `wordbank.js` | מאגר מילים: ברירת מחדל + שינויי משתמש + חבילת קלפים |
| `settings.js`, `storage.js` | הגדרות ושמירה בטוחה |
| `ui.js`, `style.css`, `index.html` | מסכים ועיצוב |

## הוספת טאבו בהמשך

1. ליצור `words-taboo-he.js` שמגדיר `window.TABOO_WORDS` באותו מבנה, כשכל קלף הוא `{ w: "מילה", f: ["אסורה1", "אסורה2"] }`.
2. להוסיף אותו ל-`index.html` לפני `storage.js` (יש שם הערה).

`modes.js` כבר מגדיר את המצב (כפתור "אסור!", קנס ותצוגת מילים אסורות), והוא יופיע בהגדרות אוטומטית.
